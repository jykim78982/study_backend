# 생성자 함수와 new 연산자 오답노트

### 1. 자바스크립트에서 생성자 함수를 new와 함께 호출했을 때의 특징은?

**문제**: 자바스크립트에서 생성자 함수를 new와 함께 호출했을 때의 특징은?

1. new 호출에서는 항상 undefined가 반환된다
2. new 호출에서는 새로 생성된 객체가 this로 연결되고 생성된 인스턴스가 반환된다
3. new 호출과 일반 호출 모두 this가 전역 객체를 가리킨다
4. new 호출에서는 this가 호출한 함수의 외부 스코프를 가리킨다

**정답: 2번**

- 함수에 `new` 키워드를 붙여 호출하면 내부적으로 다음 4단계가 자동으로 일어난다.
  1. 새 빈 객체(`{}`) 생성
  2. 생성자 함수 내부의 `this`가 방금 만든 객체에 바인딩
  3. 생성된 객체의 `__proto__`가 생성자 함수의 `prototype`을 참조
  4. 명시적인 `return`이 없어도 새로 만든 인스턴스가 자동으로 반환

```javascript
function Person(name) {
  // new 호출 시 내부적으로 빈 객체 {} 생성 및 this 바인딩
  this.name = name; // 생성된 객체에 속성 추가
  // return 문이 없어도 this(새 객체)가 자동으로 반환됨
}

const user = new Person('홍길동');
console.log(user.name); // '홍길동'
```

**1번이 오답인 이유**: 일반 함수의 기본 반환값은 `undefined`이지만, `new`로 호출되면 명시적으로 다른 객체를 `return`하지 않는 한 새로 생성된 인스턴스가 기본으로 반환된다.

**3번이 오답인 이유**: `new` 없이 일반 함수로 호출했을 때만 `this`가 전역 객체(`window` 또는 Node.js의 `global`)를 가리킨다. `new`를 쓰면 새로 생성된 객체를 가리킨다.

**4번이 오답인 이유**: 외부 스코프를 가리키는 `this`는 화살표 함수의 렉시컬 `this` 특성이다. 화살표 함수는 애초에 생성자 함수로 쓸 수 없어 `new` 자체를 사용할 수 없다.

**한 줄 요약**: `new` 연산자는 새 빈 객체를 만들어 `this`에 묶어주고, 별도의 `return`이 없으면 그 객체를 자동으로 반환한다.
