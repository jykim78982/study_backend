# CSS 선택자 오답노트

### 1. `[attr~="value"]`의 동작 방식으로 옳은 것은?

**문제**: 속성 선택자 중 `[attr~="value"]`의 동작 방식으로 옳은 것은?

1. 공백으로 구분된 토큰 목록 중 하나가 정확히 value인 경우 매칭된다.
2. 속성값이 정확히 value와 일치해야 매칭된다.
3. 속성값의 임의 위치에 value 문자열이 포함되면 매칭된다.
4. 속성값이 value로 시작하거나 하이픈 뒤에 이어지는 경우 매칭된다.

**정답: 1번**

- `~=`는 **토큰 일치 선택자**다. 속성값을 공백(space)으로 구분된 단어(토큰) 목록으로 보고, 그 목록 중 하나가 지정한 value와 **정확히 일치**할 때만 매칭된다. 예를 들어 `class="btn primary danger"`인 요소는 `[class~="primary"]`에 매칭된다.
- 나머지 보기는 각각 다른 연산자의 설명이라 헷갈리기 쉽다.

| 보기 | 실제 연산자 | 이름 | 설명 |
|---|---|---|---|
| 2번 | `[attr="value"]` | 완전 일치 | 속성 전체 값이 value와 토씨 하나 틀리지 않고 정확히 같아야 매칭 |
| 3번 | `[attr*="value"]` | 부분 문자열 일치 | 공백 구분 여부와 상관없이, 속성값 안 어느 위치든 문자열이 포함만 되면 매칭(예: `class="my-btn-style"` → `[class*="btn"]`에 매칭) |
| 4번 | `[attr\|="value"]` | 하이픈 언어/접두사 | 속성값이 정확히 value이거나, value 뒤에 하이픈(`-`)으로 시작하는 값이면 매칭. 주로 언어 코드에 씀(예: `lang="en"` 또는 `lang="en-US"` → `[lang\|="en"]`에 매칭) |

- 자주 헷갈리는 시작/끝 연산자도 함께 정리:
  - `[attr^="value"]`: 속성값이 value로 **시작**하면 매칭 (예: `href^="https"` → 보안 링크만 선택)
  - `[attr$="value"]`: 속성값이 value로 **끝**나면 매칭 (예: `href$=".pdf"` → PDF 파일 링크만 선택)
- `~=`와 `*=`를 혼동하기 쉬운데, 핵심 차이는 **"공백으로 나뉜 완전한 단어 하나"**(`~=`)냐 **"위치 상관없는 부분 문자열"**(`*=`)이냐다. `[class~="btn"]`은 `class="my-btn"`에는 매칭되지 않지만(단어 전체가 `my-btn`이라 `btn`과 정확히 같지 않음), `[class*="btn"]`은 매칭된다.
