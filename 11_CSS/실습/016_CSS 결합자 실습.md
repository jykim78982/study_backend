# CSS 결합자 실습

`publishing/css/step1/ex2-css-selector.html` 실습. 자손·자식·인접 형제·일반 형제 4가지 결합자를 같은 HTML 구조에 하나씩 적용해가며 걸리는 범위가 어떻게 달라지는지 비교했다.

## 실습 환경

```html
<div class="parent">
  부모 컨테이너 (.parent)
  <p class="first-child">자식 문단 1 (.first-child)</p>
  <p class="second-child">자식 문단 2 (.second-child)</p>
  <div class="inner">
    중간 컨테이너 (.inner)
    <p class="grandchild">자손 문단 (.grandchild)</p>
  </div>
  <p class="third-child">자식 문단 3 (.third-child)</p>
</div>
<p class="adjacent">부모 바로 다음 문단 (.adjacent)</p>
<p class="general-1">부모 이후 일반 형제 문단 1 (.general-1)</p>
<p class="general-2">부모 이후 일반 형제 문단 2 (.general-2)</p>
```

`.parent` 안에는 직계 자식 `p` 3개(`.first-child`, `.second-child`, `.third-child`)와, `.inner`라는 한 단계 더 감싸진 컨테이너 안에 손자뻘 `p` 1개(`.grandchild`)가 있다. `.parent` 바깥에는 형제 `p`가 3개(`.adjacent`, `.general-1`, `.general-2`) 이어진다. 이 구조 하나로 4가지 결합자의 차이를 전부 비교할 수 있다.

## 1단계: 자손 결합자 (공백) — `A B`

```css
.parent p {
  color: blue;
}
```

- **기능**: `A` 요소 내부에 있는 모든 `B` 요소를 선택한다. 자식이든 손자든 증손이든, 몇 단계를 거쳐 들어가 있는지는 상관하지 않는다.
- **동작 원리**: `.parent` 태그 안쪽에 위치한 모든 `<p>`를 깊이와 상관없이 전부 찾아낸다.
- **결과 확인**: `.first-child`, `.second-child`, `.third-child`뿐 아니라 `.inner` 안에 한 단계 더 중첩된 `.grandchild`까지 포함해서, 총 4개의 문단 글자색이 파란색으로 바뀐다.

## 2단계: 자식 결합자 `>` — `A > B`

```css
.parent > p {
  border-color: red;
  border-width: 2px;
}
```

- **기능**: `A` 요소의 **직계 자식**(바로 한 단계 아래)인 `B` 요소만 선택한다.
- **동작 원리**: `.parent` 바로 아래에 있는 자식 `<p>`만 선택하며, `.inner`로 한 번 더 감싸진 손자 요소는 건너뛴다.
- **결과 확인**: `.first-child`, `.second-child`, `.third-child` 3개에만 빨간색 테두리가 적용된다. `.grandchild`는 `.parent`의 직계 자식이 아니라(직계 자식은 `.inner`이고 `.grandchild`는 `.inner`의 자식이다) 대상에서 제외된다.

## 3단계: 인접 형제 결합자 `+` — `A + B`

```css
.parent + p {
  background-color: yellow;
  font-weight: bold;
}
```

- **기능**: `A`와 같은 부모를 공유하는 형제 중, `A` 바로 다음에 인접해 있는 **딱 1개**의 `B` 요소만 선택한다.
- **동작 원리**: `.parent`의 닫는 태그(`</div>`) 바로 다음에 등장하는 첫 번째 형제 요소 `<p>`를 찾는다.
- **결과 확인**: `.parent` 바로 뒤에 붙어 있는 `.adjacent` 요소 1개만 노란 배경과 굵은 글씨가 적용된다. 그 뒤에 이어지는 `.general-1`, `.general-2`는 "바로 다음"이 아니므로 무시된다.

## 4단계: 일반 형제 결합자 `~` — `A ~ B`

```css
.parent ~ p {
  text-decoration: underline;
}
```

- **기능**: `A`와 같은 부모를 공유하는 형제 중, `A` **뒤에 등장하는 모든** `B` 요소를 선택한다. 바로 인접해 있을 필요는 없다.
- **동작 원리**: `.parent` 뒤에 순서상 위치하는 형제 레벨의 모든 `<p>` 태그를 전부 선택한다.
- **결과 확인**: `.adjacent`, `.general-1`, `.general-2` 세 문단 전체에 밑줄이 적용된다.

## 결합자 핵심 비교

| 기호 | 명칭 | 대상 범위 |
|---|---|---|
| (공백) | 자손 결합자 | 하위 계층 전체(자식, 손자 등 모든 후손) |
| `>` | 자식 결합자 | 바로 아래 1계층 자식만 |
| `+` | 인접 형제 결합자 | 같은 부모 아래에서 바로 뒤에 붙은 첫 번째 형제 1개 |
| `~` | 일반 형제 결합자 | 같은 부모 아래에서 뒤따라 나오는 모든 형제 |

4단계를 순서대로 적용해보면 "범위가 가장 넓은 자손 결합자(4개) → 그보다 좁은 자식 결합자(3개, 손자 제외) → 형제 관계로 넘어가면 가장 좁은 인접 형제(1개) → 다시 넓어지는 일반 형제(3개)" 순으로 대상 개수가 달라지는 걸 한 화면에서 비교할 수 있었다.
