# 구글 아이콘 사용법과 CSS 아이콘 라이브러리 실습

`publishing/css/icon/step1.html` ~ `step6.html` 실습. 구글 Material 아이콘을 HTML에 직접 쓰는 가장 쉬운 방법부터, HTML을 건드리지 않고 CSS만으로 재사용 가능한 아이콘 라이브러리를 만드는 방법까지 6단계로 확장했다.

구글 아이콘은 이미지 파일이 아니라 **특수 폰트(글자)**다. `<span>`이나 `<i>` 태그 사이에 구글이 정해둔 영어 단어(또는 고유 코드)를 적으면, 그 글자가 폰트 렌더링을 통해 아이콘 모양으로 바뀐다.

## Step 1. 태그 안에 영어 단어 쓰기 — 가장 쉬운 기본형

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>Step 1</title>
  <!-- 구글 아이콘 폰트를 웹에서 가져오는 링크 -->
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined" />
</head>
<body>
  <!-- 클래스 이름은 반드시 material-symbols-outlined 로 지정 -->
  <span class="material-symbols-outlined">home</span>
  <span class="material-symbols-outlined">search</span>
  <span class="material-symbols-outlined">favorite</span>
  <span class="material-symbols-outlined">settings</span>
</body>
</html>
```

- **확인할 점**: 영어 단어 `home`을 적었는데 화면에는 집 모양 아이콘이 뜬다.
- **원리**: `<link>`로 불러온 구글 폰트 파일이 `home`이라는 철자를 인식해서 집 그림 글자로 바꿔준다. 클래스 이름은 반드시 구글이 정해둔 `material-symbols-outlined`를 써야 이 폰트가 적용된다.
- 실제 실습 파일에는 `.icon { font-family: "Material Symbols Outlined" }`를 직접 선언하고 클래스명을 `icon`으로 바꿔보는 대안 코드가 주석으로 남아 있다 — 즉 `material-symbols-outlined`라는 기본 클래스명 대신, 폰트를 직접 지정하면 원하는 클래스명으로도 같은 효과를 낼 수 있다는 걸 미리 실험해둔 흔적이다.

## Step 2. 폰트니까 글자 색과 크기 바꿔보기

아이콘이 곧 글자이므로, 평소 텍스트를 꾸밀 때 쓰던 `color`와 `font-size`가 그대로 적용된다.

```css
/* 색상 변경 */
.red-icon {
  color: red;
}
.blue-icon {
  color: blue;
}

/* 크기 변경 */
.big-icon {
  font-size: 48px;
}
```

```html
<!-- 기본 검은색 -->
<span class="material-symbols-outlined">favorite</span>

<!-- 빨간색 하트 -->
<span class="material-symbols-outlined red-icon">favorite</span>

<!-- 파란색 큰 톱니바퀴 -->
<span class="material-symbols-outlined blue-icon big-icon">settings</span>
```

- **확인할 점**: 그림 파일 편집기 없이 CSS의 `color`와 `font-size`만으로 아이콘의 색상과 크기가 자유롭게 변한다.

## Step 3. `::before`로 아이콘 띄우기 — 번역 깨짐 방지

HTML 태그 안에 `home`, `search` 같은 글자를 직접 적어두면, 웹페이지를 한국어로 자동 번역할 때 `home`이 "집"으로 번역되어 아이콘이 깨지는 문제가 생긴다. 이를 해결하려고 HTML은 비워두고, `::before`와 `content` 속성으로 아이콘 이름을 CSS 쪽에 옮겨 넣는다.

```css
/* [공통] 아이콘 폰트를 쓰겠다고 선언 */
.icon::before {
  font-family: "Material Symbols Outlined";
  font-size: 24px;
}

/* [개별] 어떤 아이콘 글자를 넣을지 지정 */
.icon-home::before {
  content: "home";
}
.icon-search::before {
  content: "search";
}
.icon-heart::before {
  content: "favorite";
}
```

```html
<!-- 태그 사이에 글자를 적지 않아도 아이콘이 나타납니다 -->
<i class="icon icon-home"></i>
<i class="icon icon-search"></i>
<i class="icon icon-heart"></i>
```

- **확인할 점**: `<i>` 태그 안이 완전히 비어 있지만, 브라우저는 CSS `content`에 적힌 글자를 읽어와 아이콘을 렌더링한다.
- 이 구조는 [[051_CSS — 배경 이미지·컬러·마스크·인라인 박스·포지션]]의 "패딩 vs 가상 엘리먼트" 절에서 다룬 원칙과 같은 맥락이다 — 콘텐츠(글자)가 아니라 순수 장식 목적이라면 HTML을 직접 건드리지 않고 가상 엘리먼트로 분리하는 쪽이 더 세련된 방식이다.

## Step 4. 글자 이름 대신 고유 번호(유니코드) 넣기

구글 아이콘 사이트에서 아이콘을 클릭하면 각 아이콘마다 고유한 코드 번호(예: `e88a`, `e8b6`)가 적혀 있다. `content: "home"` 대신 이 고유 번호를 `\e88a` 형태로 적으면 더 안전하고 브라우저가 더 정확하게 아이콘을 찾는다.

```css
/* 공통 폰트 지정 */
.icon::before {
  font-family: "Material Symbols Outlined";
  font-size: 24px;
}

/* 고유 코드로 아이콘 매핑 (\ 뒤에 코드 입력) */
.icon-home::before {
  content: "\e88a"; /* home의 고유 코드 */
}
.icon-search::before {
  content: "\e8b6"; /* search의 고유 코드 */
}
.icon-menu::before {
  content: "\e5d2"; /* menu의 고유 코드 */
}
.icon-close::before {
  content: "\e5cd"; /* close(X)의 고유 코드 */
}
```

```html
<span class="icon icon-home"></span>
<span class="icon icon-search"></span>
<span class="icon icon-menu"></span>
<span class="icon icon-close"></span>
```

## Step 5. 클래스로 색상과 크기 부품 조립하기 — 나만의 아이콘 라이브러리

CSS 변수나 복잡한 문법 없이, 부품 클래스(유틸리티 클래스)를 만들어 레고 블록처럼 조합하는 실무 방식이다.

```css
/* 1. 기본 아이콘 규격 */
.icon {
  display: inline-block;
  vertical-align: middle;
  color: inherit; /* 부모 태그(버튼 등)의 글자색을 그대로 따라감 */
}
.icon::before {
  font-family: "Material Symbols Outlined";
  font-size: 24px; /* 기본 크기 */
}

/* 2. 아이콘 모양 정의 */
.icon-home::before { content: "\e88a"; }
.icon-search::before { content: "\e8b6"; }
.icon-heart::before { content: "\e87d"; }
.icon-close::before { content: "\e5cd"; }

/* 3. 크기 조절용 부품 클래스 */
.size-sm::before { font-size: 18px; }
.size-lg::before { font-size: 36px; }
.size-xl::before { font-size: 48px; }

/* 4. 색상 조절용 부품 클래스 */
.color-red { color: #e74c3c; }
.color-blue { color: #3498db; }
.color-green { color: #2ecc71; }

/* 5. 버튼에 활용해보기 */
.btn {
  background-color: #2c3e50;
  color: white;
  padding: 10px 18px;
  border: none;
  border-radius: 6px;
  font-size: 16px;
  cursor: pointer;
}
```

```html
<h3>1. 기본 아이콘</h3>
<span class="icon icon-home"></span>
<span class="icon icon-search"></span>

<h3>2. 크기와 색상 클래스 덧붙이기 (조합)</h3>
<!-- 빨간색 하트 -->
<span class="icon icon-heart size-sm color-red"></span>

<!-- 파란색 특대형 홈 아이콘 -->
<span class="icon icon-home size-xl color-blue"></span>

<!-- 초록색 대형 닫기 아이콘 -->
<span class="icon icon-close size-lg color-green"></span>

<h3>3. 버튼 안에서 텍스트와 함께 쓰기</h3>
<button class="btn">
  <span class="icon icon-search"></span> 검색하기
</button>
```

- 가이드 원문 예제는 빨간 하트에 `icon-heart color-red`만 붙였지만, 실제 실습 코드는 `icon-heart size-sm color-red`로 **크기 클래스(`size-sm`)까지 함께 조합**해서 테스트했다 — 부품 클래스가 실제로 여러 개 동시에 붙어도 서로 충돌 없이 조합되는지 직접 확인해본 흔적이다.
- **핵심**: `.icon`(공통 규격) + `.icon-*`(모양) + `.size-*`(크기) + `.color-*`(색상)처럼 역할별로 클래스를 쪼개 두면, `class="icon icon-home size-xl color-blue"`처럼 필요한 클래스를 띄어쓰기로 이어 붙여(멀티 클래스) 원하는 조합을 자유롭게 만들 수 있다.

### 수업 진행 팁 (원문 메모)

- Step 1~2에서 아이콘이 폰트라는 점을 먼저 이해시킨다.
- Step 3~4에서 HTML 코드와 디자인 요소를 분리하는 이유(번역 깨짐 방지, 깔끔한 마크업)를 짚는다.
- Step 5에서 `.icon`, `.icon-home`, `.color-red`, `.size-lg`처럼 필요한 클래스를 조합하는 멀티 클래스 방식을 실습시킨다.

## Step 6. 아이콘으로 콘텐츠를 꾸미는 라이브러리 — 최종

Step 3~5는 `<span>`/`<i>` 태그 안이 비어 있고 **아이콘 자체가 콘텐츠**인 경우였다. 반대로 아이콘이 콘텐츠(텍스트)를 꾸며주기만 하는 경우도 실무에서 자주 쓰인다 — 이번 단계는 그 두 방식을 조합한다.

- **아이콘이 곧 콘텐츠가 되는 경우**: HTML을 이용하는 방법(Step 1~2 방식)이 낫다.
- **아이콘이 콘텐츠가 아니라 꾸며주기만 하는 경우**: CSS만으로 꾸미는 방법(Step 3~5 방식)이 낫다.
- 두 방식 모두 효용가치가 있으니, 필요에 따라 선택적으로 써야 한다.

```css
/* 1. 기본 아이콘 규격 */
.icon {
    display: inline-block;
    vertical-align: middle;
    color: inherit;

    /* 컨텐츠와 아이콘이 수평이 어울릴 수 있도록 꾸며줍니다. */
    display: inline-flex;
    align-items: center;
}

.icon::before {
    font-family: "Material Symbols Outlined";
    font-size: 24px;
}

/* 2. 아이콘 모양 정의 */
.icon-home::before {
    content: "\e88a";
}

.icon-search::before {
    content: "\e8b6";
}

/* 3. 크기 조절용 부품 클래스 */
.size-sm::before {
    font-size: 18px;
}

.size-lg::before {
    font-size: 36px;
}

.size-xl::before {
    font-size: 48px;
}

/* 4. 색상 조절용 부품 클래스 */
.color-red {
    color: #e74c3c;
}

.color-blue {
    color: #3498db;
}

.color-green {
    color: #2ecc71;
}
```

```html
<h3>1. 콘텐츠만으로 이루어진 구조</h3>
<span>홈</span>
<span>검색</span>

<h3>2. 콘텐츠 구조에 아이콘 클래스를 사용하기</h3>
<span class="icon icon-home size-sm color-green">홈</span>
<span class="icon icon-search size-sm">검색</span>
```

- **핵심 변경점**: `.icon`에 `display: inline-block` 뒤에 `display: inline-flex; align-items: center;`를 다시 선언했다. 같은 속성을 두 번 쓴 것처럼 보이지만, CSS는 나중에 선언한 값이 이기므로 최종적으로는 `inline-flex`가 적용된다 — 아이콘(`::before`)과 뒤따라오는 텍스트("홈", "검색")가 세로로 어긋나지 않고 수평으로 나란히 정렬되게 하려는 목적이다.
- **확인할 점**: `icon-home`/`icon-search` 클래스가 붙은 `<span>`은 앞에 아이콘이 자동으로 붙은 채로, 뒤에 적어둔 "홈"/"검색" 텍스트와 함께 표시된다 — 아이콘은 순수 장식이고, "홈"/"검색"이라는 실제 콘텐츠는 그대로 HTML에 남아 있다.

## Step 1~6 요약

| 단계 | 방식 | 언제 쓰는가 |
|---|---|---|
| 1~2 | HTML에 아이콘 이름을 직접 텍스트로 씀 | 아이콘 자체가 콘텐츠일 때 |
| 3~4 | `::before` + `content`로 CSS에서 아이콘 삽입 | 마크업을 깔끔하게 유지하고 번역 깨짐을 막고 싶을 때 |
| 5 | `.icon` + `.icon-*` + `.size-*` + `.color-*` 부품 클래스 조합 | 재사용 가능한 아이콘 라이브러리를 만들 때 |
| 6 | 5번 방식에 실제 텍스트 콘텐츠를 함께 배치(`inline-flex`) | 아이콘이 텍스트 콘텐츠를 꾸며주기만 할 때 |
