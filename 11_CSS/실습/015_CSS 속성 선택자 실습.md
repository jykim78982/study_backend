# CSS 속성 선택자 실습

`publishing/css/step1/ex1-css-attr.html` 실습. 속성 선택자 8가지 문법을 하나씩 추가해가며 어떤 요소가 걸리는지 눈으로 확인했다.

## 실습 환경

```html
<!-- 언어 속성 실습용 요소 -->
<p><span lang="ko">한국어 텍스트 (lang="ko")</span></p>
<p><span lang="pt">포르투갈어 텍스트 (lang="pt")</span></p>
<p><span lang="en-us text">단어 포함 텍스트 (lang="en-us text")</span></p>
<p><span lang="zh-CN">중국어 간체 (lang="zh-CN")</span></p>
<p><span lang="zh-TW">중국어 번체 (lang="zh-TW")</span></p>
<p><span>속성 없는 일반 텍스트</span></p>
<hr>
<!-- 링크 속성 실습용 요소 -->
<p><a href="#section1">내부 링크 (href="#section1")</a></p>
<p><a href="https://site.cn">중국 도메인 예시 링크 (href="https://site.cn")</a></p>
<p><a href="https://example.com/page">예제 링크 (href="https://example.com/page")</a></p>
<p><a href="https://google.com">일반 외부 링크 (href="https://google.com")</a></p>
<hr>
<!-- 대소문자 플래그 실습용 요소 -->
<p><input type="email" value="user@domain.com"></p>
<p><input type="EMAIL" value="UPPERCASE@domain.com"></p>
<p><input type="text" value="일반 텍스트 입력창"></p>
```

## 1단계: `[attr]` — 속성 존재 여부만 확인

```css
span[lang] { font-weight: bold; }
```

- **기능**: 값이 무엇이든 상관없이, 지정한 속성 자체를 갖고 있는 요소를 모두 선택한다.
- **동작 원리**: `lang` 속성이 존재하는 `span`만 찾아서 폰트를 굵게 만든다. 값이 `"ko"`든 `"pt"`든 상관없이 `lang`이라는 속성 이름만 있으면 걸린다.
- **결과 확인**: `lang`이 명시된 span 5개(ko, pt, en-us text, zh-CN, zh-TW)는 전부 굵게 표시되고, 속성이 아예 없는 `<span>속성 없는 일반 텍스트</span>`만 기본 굵기로 남는다.

## 2단계: `[attr=value]` — 완전 일치

```css
span[lang="pt"] { color: green; }
```

- **기능**: 속성값이 지정한 값과 **정확히 같을 때만** 선택한다. 부분 일치나 포함 관계는 인정하지 않는다.
- **동작 원리**: `lang`의 값이 정확히 문자열 `"pt"`인 요소만 매칭한다.
- **결과 확인**: `<span lang="pt">` 하나만 초록색으로 바뀐다. `lang="zh-CN"`처럼 앞부분이 겹쳐도 값 전체가 다르면 걸리지 않는다.

## 3단계: `[attr~=value]` — 공백으로 구분된 단어 중 하나 포함

```css
span[lang~="en-us"] { color: blue; }
```

- **기능**: 속성값이 공백으로 구분된 여러 단어의 목록이라고 볼 때, 그 목록 안에 지정한 단어가 **정확히 하나 포함**되어 있으면 선택한다.
- **동작 원리**: `lang="en-us text"`는 `"en-us"`와 `"text"` 두 단어로 이루어진 목록으로 취급된다. 이 중 `"en-us"`라는 단어가 정확히 포함되어 있는지를 검사한다. 부분 문자열 포함이 아니라 **공백으로 쪼갠 단어 단위 비교**라는 점이 `[attr*=value]`(7단계)와 다르다.
- **결과 확인**: `<span lang="en-us text">` 하나만 파란색으로 바뀐다.

## 4단계: `[attr|=value]` — 값이거나 하이픈으로 시작하는 값

```css
span[lang|="zh"] { color: red; }
```

- **기능**: 속성값이 지정한 값과 정확히 같거나, 그 값 바로 뒤에 하이픈(`-`)이 붙어서 시작하는 경우를 선택한다. 언어 코드(`zh`, `zh-CN`, `zh-TW`처럼 국가 서브태그가 붙는 형태)를 다루기 위해 만들어진 문법이다.
- **동작 원리**: 값이 `"zh"`이거나 `"zh-"`로 시작하면 매칭된다. `zh-CN`과 `zh-TW`는 둘 다 `"zh-"`로 시작하므로 함께 걸린다.
- **결과 확인**: `<span lang="zh-CN">`과 `<span lang="zh-TW">` 두 개가 모두 빨간색으로 바뀐다.

## 5단계: `[attr^=value]` — 접두사(시작 문자열) 일치

```css
a[href^="#"] { background-color: gold; }
```

- **기능**: 속성값이 지정한 문자열로 **시작**하는 요소를 선택한다.
- **동작 원리**: `href`의 첫 글자가 `#`인 링크, 즉 같은 문서 안의 앵커로 이동하는 내부 링크를 찾아낸다.
- **결과 확인**: `href="#section1"` 링크의 배경색이 금색(gold)으로 바뀐다.

## 6단계: `[attr$=value]` — 접미사(끝 문자열) 일치

```css
a[href$=".cn"] { color: red; }
```

- **기능**: 속성값이 지정한 문자열로 **끝**나는 요소를 선택한다.
- **동작 원리**: `href`의 끝부분이 `.cn`으로 끝나는 URL, 즉 중국 도메인 예시 링크를 찾는다.
- **결과 확인**: `href="https://site.cn"` 링크의 글자색이 빨간색으로 바뀐다.

## 7단계: `[attr*=value]` — 부분 문자열 포함(위치 무관)

```css
a[href*="example"] { background-color: #cccccc; }
```

- **기능**: 속성값 안 어느 위치에든 지정한 문자열이 **포함만** 되어 있으면 선택한다. 시작이든 끝이든 중간이든 상관없다.
- **동작 원리**: `href` 안에 `"example"`이라는 문자열이 들어있는지만 검사한다.
- **결과 확인**: `href="https://example.com/page"` 링크의 배경색이 회색(`#cccccc`)으로 바뀐다.

## 8단계: `[attr=value i]` — 대소문자 구분 없이 비교

```css
input[type="email" i] { border: 2px solid blue; }
```

- **기능**: 값 매칭 시 대소문자를 구분하지 않도록 만드는 `i` 플래그다. 지금까지의 모든 비교 연산자(`=`, `~=`, `|=`, `^=`, `$=`, `*=`) 뒤에 공통으로 붙일 수 있다.
- **동작 원리**: 대소문자 구분 없이 `email`, `EMAIL`, `Email` 등 모든 표기를 동일한 값으로 취급한다.
- **결과 확인**: `<input type="email">`과 `<input type="EMAIL">` 둘 다 파란 테두리가 적용되고, `<input type="text">`는 기본 테두리를 유지한다.
