# CSS 그라데이션 실습 — 선형·원형·원뿔형·반복·다중 배경

`publishing/css/gradient/step1.html` ~ `step8.html` 실습. 선형·원형·원뿔형 그라데이션의 기초부터, 그라데이션 반복 패턴, 실제 사진과 그라데이션을 겹치는 다중 배경 이미지, 마지막으로 3단 레이어를 합성한 실무 카드 UI까지 8단계로 진행했다.

## Step 1. 선형 그라데이션의 기초 (`linear-gradient`)

선형 그라데이션은 직선 방향으로 색상이 서서히 바뀌는 효과다. 기본값은 위에서 아래 방향이다.

```css
.box {
  width: 320px;
  height: 160px;
  border-radius: 8px;
  margin-bottom: 20px;
}

/* 1. 기본형: 위에서 아래로 (#e74c3c -> #f39c12) */
.linear-basic {
  background: linear-gradient(#e74c3c, #f39c12);
}

/* 2. 3가지 이상의 색상 연결 */
.linear-multi {
  background: linear-gradient(#e74c3c, #f1c40f, #2ecc71, #3498db, #aa0aaa);
}
```

- **관찰 포인트**: 색상을 쉼표(`,`)로 나열하기만 하면 균등한 비율로 부드럽게 섞인다.
- 실제 실습 코드는 `.linear-multi`에 가이드 원문(4색)보다 색을 하나 더 추가해(`#aa0aaa`, 보라 계열) 총 5가지 색을 연결해봤다 — 색상 수를 늘려도 각 구간이 자동으로 균등 분배된다는 걸 직접 확인해본 것으로 보인다.

## Step 2. 선형 그라데이션 방향과 각도 제어하기

색이 흐르는 방향을 키워드(`to ...`)나 각도(`deg`)로 지정할 수 있다.

```css
.box {
  width: 320px;
  height: 140px;
  border-radius: 8px;
  margin-bottom: 15px;
}

/* 1. 왼쪽에서 오른쪽으로 */
.to-right {
  background: linear-gradient(to right, #3498db, #2ecc71);
}

/* 2. 대각선 방향 (왼쪽 아래에서 오른쪽 위로) */
.to-diagonal {
  background: linear-gradient(to top right, #8e44ad, #e74c3c);
}

/* 3. 시계 방향 회전 각도 (135도) */
.with-angle {
  background: linear-gradient(135deg, #11998e, #38ef7d);
}
```

- **관찰 포인트**: `0deg`는 아래에서 위, `90deg`는 왼쪽에서 오른쪽, `180deg`는 위에서 아래(기본값)다.

## Step 3. 원형 그라데이션 (`radial-gradient`)

중심점에서 바깥쪽으로 원이나 타원 형태로 동심원을 그리며 퍼져나간다.

```css
.box {
  width: 300px;
  height: 200px;
  border-radius: 12px;
  margin-bottom: 20px;
}

/* 1. 기본 타원형: 박스 가로세로 비율에 맞춰 자연스러운 타원으로 퍼짐 */
.radial-basic {
  background: radial-gradient(#f1c40f, #e67e22);
}

/* 2. 완전한 정원(circle) 형태로 퍼지게 강제 */
.radial-circle {
  background: radial-gradient(circle, #3498db, #2c3e50);
}

/* 3. 중심점 이동: 정중앙이 아닌 왼쪽 상단(at left top)에서 시작 */
.radial-position {
  background: radial-gradient(circle at left top, #ff7675, #2d3436);
}

/* 4. 중심점을 픽셀 좌표로 직접 지정 */
.radial-position2 {
  background: radial-gradient(circle at 100px 50px, #ff0acc, #2d3436);
}
```

- **관찰 포인트**: `circle at X위치 Y위치`를 사용하면 전등 불빛이나 조명 핀포인트 효과를 연출할 수 있다.
- 실습 코드는 가이드 원문 3개 예제에 `.radial-position2`를 추가로 실습했다 — `at left top` 같은 키워드 대신 `at 100px 50px`처럼 **픽셀 좌표로 중심점을 직접 지정**할 수 있다는 걸 확인한 것이다. 키워드 방식과 좌표 방식 둘 다 가능하다는 뜻이다.

## Step 4. 원뿔형 그라데이션 (`conic-gradient`)

나침반 바늘이 돌듯 중심축을 기준으로 각도를 회전하며 색이 변한다. 원형 차트나 무지개 휠을 만들 때 쓴다.

```css
.circle {
  width: 180px;
  height: 180px;
  border-radius: 50%; /* 완전한 원 */
  margin-bottom: 20px;
}

/* 1. 기본 색상 휠 */
.conic-basic {
  background: conic-gradient(#e74c3c, #f1c40f, #2ecc71, #3498db, #e74c3c);
}

/* 2. 파이 차트 만들기 (경계선을 칼처럼 끊어내는 색상 정지점 테크닉) */
.conic-pie {
  background: conic-gradient(
    #3498db 0% 60%,   /* 0%부터 60%까지 파란색 */
    #e74c3c 60% 85%,  /* 60%부터 85%까지 빨간색 */
    #f1c40f 85% 100%  /* 85%부터 100%까지 노란색 */
  );
}
```

- **관찰 포인트**: 색상 뒤에 퍼센트 구간(`0% 60%`)을 명시하면 중간 번짐(보간) 없이 경계선이 딱 잘리는 도넛/파이 차트가 만들어진다.

## Step 5. 그라데이션 반복하기 (`repeating-*`)

그라데이션 패턴을 자동으로 끝없이 반복시켜 스트라이프(줄무늬)나 과녁 패턴을 만든다.

```css
.box {
  width: 320px;
  height: 120px;
  border-radius: 8px;
  margin-bottom: 20px;
}

/* 1. 빗살무늬 안전 테이프 패턴 (선형 반복) */
.stripe-pattern {
  background: repeating-linear-gradient(
    45deg,
    #f1c40f 0,
    #f1c40f 15px,
    #2c3e50 15px,
    #2c3e50 30px
  );
}

/* 2. 동심원 과녁 패턴 (원형 반복) */
.target-pattern {
  background: repeating-radial-gradient(
    circle,
    #e74c3c,
    #e74c3c 15px,
    #ffffff 15px,
    #ffffff 30px
  );
}
```

- **관찰 포인트**: 시작 픽셀과 종료 픽셀을 명확히 맞물리게 지정하면 이미지 파일 없이 CSS 코드만으로 고품질 타일 패턴을 생성할 수 있다.
- 실습 코드는 `.stripe-pattern`의 첫 색상 정지점을 가이드 원문의 `#f1c40f,`(시작 위치 생략)이 아니라 `#f1c40f 0,`처럼 **시작 위치(`0`)를 명시적으로 적었다** — 생략하면 자동으로 `0`(구간 시작점)으로 처리되므로 결과는 동일하지만, 색상 정지점 문법이 `색상 위치` 형태라는 걸 명확히 보여주려는 표기다.

## Step 6. 2장 이상의 배경 이미지 겹치기 — 다중 배경 기본 원리

실제 이미지 파일 여러 개를 다룬다. CSS는 쉼표(`,`)를 기준으로 **먼저 쓴 이미지가 가장 앞(위)**에 올라온다.

```css
.stage {
  width: 500px;
  height: 300px;
  border: 3px solid #2c3e50;
  border-radius: 12px;

  /*
    [중요] 쉼표로 2개의 이미지를 선언
    첫 번째: 작은 투명 PNG 캐릭터 (위)
    두 번째: 넓은 방 배경 사진 (아래)
  */
  background-image:
    url('https://cdn-icons-png.flaticon.com/512/1998/1998621.png'),
    url('https://picsum.photos/id/1018/800/500');

  /*
    [속성 짝 맞추기]
    앞쪽 값 = 1번 캐릭터 / 뒤쪽 값 = 2번 배경 사진
  */
  background-repeat:
    no-repeat,
    no-repeat;

  background-position:
    bottom 20px right 30px, /* 캐릭터: 우측 하단 */
    center center;           /* 배경사진: 정중앙 */

  background-size:
    100px 100px,  /* 캐릭터: 100x100 고정 크기 */
    cover;        /* 배경사진: 공간 가득 채우기 */
}
```

- **주의할 점**: 만약 순서를 바꾸어 `url(배경사진), url(캐릭터)`로 쓰면 불투명한 배경 사진 뒤로 캐릭터가 가려져 보이지 않게 된다.
- **핵심 원리**: `background-image`에 이미지를 여러 개 나열하면, `background-repeat`/`background-position`/`background-size`도 **같은 순서로 값을 쉼표로 나열해서 각 이미지에 짝을 맞춰줘야** 한다. N번째 이미지는 각 속성의 N번째 값을 적용받는다.

## Step 7. 실무 필수 — 사진 위에 반투명 그라데이션 오버레이 얹기

실무에서 배경 사진 위에 글씨를 쓸 때, 사진의 밝은 부분 때문에 글자가 안 읽히는 문제를 해결하는 표준 기법이다.

```css
.banner {
  width: 550px;
  height: 250px;
  border-radius: 12px;
  padding: 24px;
  box-sizing: border-box;
  display: flex;
  align-items: flex-end; /* 텍스트를 박스 하단에 배치 */
  color: white;
  font-family: sans-serif;

  /*
    레이어 1 (위): 아래로 갈수록 진해지는 반투명 블랙 그라데이션
    레이어 2 (아래): 배경 사진
  */
  background-image:
    linear-gradient(to bottom, rgba(0, 0, 0, 0) 0%, rgba(0, 0, 0, 0.8) 100%),
    url('https://picsum.photos/id/1067/800/500');

  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

.banner h2 {
  margin: 0;
  font-size: 22px;
}
```

```html
<div class="banner">
  <h2>하단 그라데이션 틴트로 흰색 글자가 선명해집니다</h2>
</div>
```

- **관찰 포인트**: `rgba(0, 0, 0, 0)`(완전 투명)에서 `rgba(0, 0, 0, 0.8)`(80% 불투명 검정)으로 변하는 그라데이션이 사진 상단은 자연스럽게 보여주면서 하단 텍스트는 선명하게 살려준다.
- 이 기법은 Step 6의 "여러 이미지는 순서·짝을 맞춰 쉼표로 나열" 원리를 그대로 활용한다 — 다만 이번엔 두 번째 레이어가 이미지가 아니라 **그라데이션도 하나의 배경 이미지로 취급된다**는 점([[051_CSS — 배경 이미지·컬러·마스크·인라인 박스·포지션]] 5절)을 실전에서 응용한 사례다.

## Step 8. 최종 완성 — 3단 합성 실무 카드 UI

- **상단 레이어**: 분위기를 연출하는 컬러 틴트 그라데이션
- **중간 레이어**: 우측 상단 브랜드 로고/아이콘
- **하단 레이어**: 베이스 배경 텍스처 사진

```css
.vip-card {
  width: 440px;
  height: 250px;
  border-radius: 16px;
  padding: 28px;
  box-sizing: border-box;
  box-shadow: 0 15px 30px rgba(0, 0, 0, 0.3);
  color: #ffffff;
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  display: flex;
  flex-direction: column;
  justify-content: space-between;

  /*
    [3단 레이어 구성]
    1층(맨 위): 대각선 반투명 컬러 그라데이션 (네이비 -> 에메랄드 틴트)
    2층(중간): 우측 상단 워터마크 로고
    3층(바닥): 기본 질감 풍경 사진
  */
  background-image:
    linear-gradient(135deg, rgba(24, 43, 73, 0.9) 0%, rgba(38, 166, 154, 0.5) 100%),
    url('https://cdn-icons-png.flaticon.com/512/616/616490.png'),
    url('https://picsum.photos/id/1025/800/600');

  /* 3개 레이어의 반복 여부 짝 맞추기 */
  background-repeat:
    no-repeat,
    no-repeat,
    no-repeat;

  /* 3개 레이어의 위치 짝 맞추기 */
  background-position:
    center center,
    top 25px right 25px,
    center center;

  /* 3개 레이어의 크기 짝 맞추기 */
  background-size:
    auto,
    50px 50px,
    cover;
}

.card-top {
  display: flex;
  flex-direction: column;
  gap: 6px;
}
.card-label {
  font-size: 11px;
  letter-spacing: 2px;
  text-transform: uppercase;
  opacity: 0.8;
}
.card-title {
  font-size: 24px;
  margin: 0;
  font-weight: 700;
}
.card-number {
  font-family: monospace;
  font-size: 16px;
  letter-spacing: 3px;
  margin: 0;
  opacity: 0.9;
}
```

```html
<div class="vip-card">
  <div class="card-top">
    <span class="card-label">Platinum Access</span>
    <h3 class="card-title">DEV PASS</h3>
  </div>
  <p class="card-number">4520 •••• •••• 9921</p>
</div>
```

- Step 6~7에서 익힌 "레이어는 쉼표로 나열하고, 반복·위치·크기 속성도 같은 순서로 짝을 맞춘다"는 원리를 3개 레이어로 확장한 최종 형태다. 그라데이션(장식) → 아이콘(브랜딩) → 사진(질감)이 위에서부터 순서대로 겹쳐 하나의 카드 UI를 완성한다.

## 8단계 요약

| 단계 | 함수/기법 | 핵심 |
|---|---|---|
| 1 | `linear-gradient(색1, 색2, ...)` | 색을 쉼표로 나열하면 균등 비율로 섞임(기본 위→아래) |
| 2 | `linear-gradient(to 방향 / 각도deg, ...)` | 방향 키워드 또는 각도로 흐름 방향 제어 |
| 3 | `radial-gradient(circle at 위치, ...)` | 중심점 기준 원/타원으로 퍼짐, 위치는 키워드·픽셀 모두 가능 |
| 4 | `conic-gradient(색 시작% 끝%, ...)` | 각도 회전 기반, 퍼센트 구간 지정 시 파이 차트처럼 경계 분리 |
| 5 | `repeating-linear/radial-gradient(...)` | 시작~끝 픽셀을 맞물리게 지정해 무한 반복 패턴 생성 |
| 6 | `background-image: url(), url()` | 먼저 쓴 이미지가 위, 반복·위치·크기도 같은 순서로 짝을 맞춤 |
| 7 | `linear-gradient(rgba...) , url()` | 그라데이션도 배경 이미지로 취급, 사진 위 텍스트 가독성 오버레이 |
| 8 | 그라데이션 + 아이콘 + 사진(3중 레이어) | 실무 카드 UI: 장식·브랜딩·질감을 레이어로 합성 |
