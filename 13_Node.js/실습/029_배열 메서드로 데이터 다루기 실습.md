# 배열 메서드로 데이터 다루기 실습

`nodeprj/step3-array-method/ex1-sort.js`에서 배열의 `sort`·`filter`·`map`을 직접 실행해보며, 화살표 함수(람다식)로 바꿔 쓰는 과정과 메서드 체이닝을 확인한 실습이다. 함께 다루는 `reduce`까지 더하면 데이터 분석에 필요한 필터링·정렬·변환·집계 네 가지를 모두 갖추게 된다.

## 1. 배열 메서드는 데이터 분석 도구다

자바스크립트 배열에는 필터링(`filter`), 정렬(`sort`), 변환(`map`) 같은 데이터 분석형 메서드가 기본으로 들어 있다. SQL과 비교하면 역할이 그대로 대응된다.

| SQL | 배열 메서드 |
|---|---|
| `WHERE` | `filter` |
| `ORDER BY` | `sort` |
| `SELECT` (컬럼 가공) | `map` |

## 2. `sort` — 기본 정렬과 비교 함수

인자 없이 `sort()`를 호출하면 문자열 기준 오름차순으로 정렬된다.

```js
let nums = ["3", "31", "123", "0", "32"];
nums.sort();
```

객체 배열처럼 무엇을 기준으로 정렬할지 `sort` 스스로 알 수 없는 경우에는, 두 값을 비교해 그 결과를 숫자로 돌려주는 비교 함수를 넘겨야 한다.

```js
let exams = [
    { kor: 10, eng: 30 },
    { kor: 70, eng: 10 },
    { kor: 50, eng: 20 },
];

exams.sort(function (a, b) {
    return (a.kor + a.eng) - (b.kor + b.eng);
});
```

비교 함수는 `a`, `b` 두 값을 받아 그 차이를 반환한다. 단순히 `a - b`로 뺄 수 없는 이유는 정렬 대상이 객체이기 때문이다 — `sort`는 데이터 구조를 모르므로, 무엇을 기준으로 비교할지는 함수를 넘겨받는 쪽(개발자)이 직접 정해야 한다.

| 비교 함수의 반환값 | 정렬 순서 |
|---|---|
| 0보다 큼 | b를 a보다 앞에 둔다 |
| 0보다 작음 | a를 b보다 앞에 둔다 |
| 0 | a와 b의 원래 순서를 유지한다 |

## 3. `filter` — 조건에 맞는 것만 남기기

조건식을 반환하는 함수를 넘기면, 그 조건을 만족하는 항목만 남는다.

```js
let result = exams.filter(function (exam) {
    return exam.kor > 20;
});
```

## 4. `map` — 값을 다른 형태로 변환하기

`map`은 배열의 각 항목을 받아 다른 값(또는 다른 모양)으로 바꿔서 새 배열을 만든다. 숫자를 가공할 수도 있고, 템플릿 리터럴로 HTML 문자열을 만들 수도 있다.

```js
let res = exams.map(exam => `<div>kor:${exam.kor}, eng:${exam.eng}</div>`);
```

## 5. `reduce` — 여러 값을 하나로 집계하기

`filter`·`sort`·`map`은 처리 결과가 다시 배열이지만, `reduce`는 배열 전체를 순회하며 **하나의 값**으로 누적해 돌려준다. 콜백은 "지금까지 누적된 값"과 "현재 항목"을 받아 다음 누적값을 반환하고, 두 번째 인자로 준 초깃값에서부터 시작한다.

```js
let total = exams.reduce((acc, exam) => acc + exam.kor, 0);
```

| SQL | 배열 메서드 |
|---|---|
| 집계 함수(`SUM` 등) | `reduce` |

## 6. 화살표 함수(람다식)로 바꿔 쓰기

`function`과 `return`을 포함한 중괄호 블록은 화살표 함수로 줄여 쓸 수 있다.

- `function` 키워드를 지우고 매개변수 뒤에 `=>`를 붙인다.
- `return` 하나만 있는 중괄호 블록이면 중괄호와 `return`을 지우고 표현식만 남긴다.
- 매개변수가 하나뿐이면 소괄호도 생략할 수 있다. 단, **매개변수가 두 개 이상이면 소괄호를 반드시 써야 한다** — `sort`의 비교 함수처럼 `(a, b) => a - b`가 대표적이다.

```js
// 원래 형태
exams.sort(function (a, b) {
    return (a.kor + a.eng) - (b.kor + b.eng);
});

// 화살표 함수로
exams.sort((a, b) => (a.kor + a.eng) - (b.kor + b.eng));

// 매개변수가 하나면 괄호도 생략 가능
exams.filter(exam => exam.kor > 20);
```

## 7. 메서드 체이닝 — 반환값을 그대로 물려받기

`filter`·`sort`·`map`은 모두 배열을 반환하므로, 반환된 배열에 바로 다음 메서드를 이어 호출할 수 있다. 반환한다는 것은 결과를 변수에 담으라는 뜻이 아니라, 뒤에 다른 메서드를 곧바로 이어 붙일 수 있다는 뜻이다.

```js
let res = exams
    .filter(exam => exam.kor > 20)                                    // WHERE
    .sort((a, b) => a.kor - b.kor)                                    // ORDER BY
    .map(exam => `<div>kor:${exam.kor}, eng:${exam.eng}</div>`);      // SELECT
```

## 8. 정리

| 메서드 | 역할 | 넘기는 함수가 반환할 값 |
|---|---|---|
| `sort` | 정렬 | 비교 결과(음수/0/양수) |
| `filter` | 조건에 맞는 항목만 남기기 | 조건식(참/거짓) |
| `map` | 각 항목을 다른 값으로 변환 | 변환된 새 값 |
| `reduce` | 전체를 하나의 값으로 집계 | 다음 누적값 |
