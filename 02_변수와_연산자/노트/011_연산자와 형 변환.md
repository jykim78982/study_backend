# 연산자와 형 변환

## 1. 형식 변환(형 변환)

변수의 크기(byte)가 다른 공간으로 값을 옮길 때, **손실 여부에 따라 묵시적/명시적 변환이 갈린다.**

```java
byte x = 1;   // 1byte로 준비된 공간에 1을 넣음
int y = x;    // 4byte로 준비된 공간에 x를 넣음
```

- 1byte인 `x`를 4byte인 `int`에 담을 때는 **공간이 넉넉해 손실이 없으므로 묵시적으로 형식 변환**된다.

```java
int x = 1;    // 4byte로 준비된 공간에 1을 넣음
byte y = x;   // 1byte로 준비된 공간에 x를 넣음
```

- 4byte인 `x`를 1byte 공간인 `y`에 넣으려 하면 **손실이 발생**하므로, **묵시적으로 형식 변환을 해 주지 않는다** (명시적 변환, 즉 캐스팅이 필요하다).

> 작은 공간 → 큰 공간: 묵시적(자동) 변환
> 큰 공간 → 작은 공간: 명시적(강제) 변환 필요

## 2. 산술 연산자

| 연산자 | 의미 |
|---|---|
| `+` | 덧셈 |
| `-` | 뺄셈 |
| `*` | 곱셈 |
| `/` | 나눗셈(몫) |
| `%` | 나머지 |

- 정수와 실수가 섞인 연산에서도 형 변환 규칙이 적용되며, 결과 타입은 더 큰(정밀한) 타입을 따라간다.

## 3. 단항 연산자 — 증가와 감소

항이 한 개인 연산자다.

| 연산자 | 의미 |
|---|---|
| `++` | 값을 1 증가시킨다 |
| `--` | 값을 1 감소시킨다 |
| `+` | 양의 부호(값 유지) |
| `-` | 부호 반전(음수화) |
| `!` | 논리값을 반전시킨다(`true` ↔ `false`) |

예시:

```java
int a = 5;
a++;   // a는 6이 됨
a--;   // a는 다시 5가 됨
```

**전위(`++X`) vs 후위(`X++`)**

- `System.out.print`에서 `++`이 **앞에 나온 경우(`++X`)**: **먼저 증가를 계산한 뒤** `print`한다.
- `System.out.print`에서 `++`이 **뒤에 나온 경우(`X++`)**: **먼저 `print`를 한 뒤** 증가를 계산한다.

예시:

```java
int x = 5;
System.out.print(++x);   // 6 출력 (먼저 증가 후 출력)

int y = 5;
System.out.print(y++);   // 5 출력 (먼저 출력 후 증가, y는 이후 6이 됨)
```

## 4. 비교 / 논리 연산자

### 비교 연산자

| 연산자 | 의미 |
|---|---|
| `==` | 같다 |
| `!=` | 같지 않다 |
| `a > b` | a가 b보다 크다 |
| `a >= b` | a가 b보다 크거나 같다 |
| `a < b` | a가 b보다 작다 |
| `a <= b` | a가 b보다 작거나 같다 |

### 논리 연산자

| 연산자 | 의미 |
|---|---|
| `&&` | 교집합 연산자 (그리고, and) |
| `\|\|` | 합집합 연산자 (또는, or) |
| `!` | 부정 연산자 |

**범위 표현 예시**

```java
// -2 < x <= 2  ->  자바에서는 이렇게 쓸 수 없으므로 && 로 풀어 쓴다
-2 < x && x <= 2
```

**활용 예 — x가 홀수이면서 3의 배수**

```java
(x % 2 == 1) && (x % 3 == 0)
```

**기타 조합 예시 — 아래 두 줄은 부정 연산자(`!`)를 사용해 같은 내용을 표현한 것이다**

```java
(x <= 2) || (4 <= x)     // x가 2 이하이거나 4 이상이다
!((2 < x) && (x < 4))    // x가 2 초과이면서 4 미만인 것이 아니다
```

## 5. 복합 대입 연산자

연산과 대입을 한 번에 처리해 코드를 간결하게 만든다.

| 연산자 | 의미 |
|---|---|
| `+=` | 덧셈 후 대입 |
| `-=` | 뺄셈 후 대입 |
| `*=` | 곱셈 후 대입 |
| `/=` | 나눗셈 후 대입 |
| `%=` | 나머지 연산 후 대입 |
| `&=` | 비트 AND 후 대입 |
| `\|=` | 비트 OR 후 대입 |
| `>>=` | 비트를 오른쪽으로 쉬프트 후 대입 |
| `<<=` | 비트를 왼쪽으로 쉬프트 후 대입 |

## 6. 비트 연산자

- **숫자를 주로 다루는 상황에서 사용**된다 — 문자 데이터를 주로 다룰 때는 잘 쓰지 않는다.
- **플랫폼, 라이브러리를 만들 때** 주로 사용된다.

### 시프트 연산자

**왼쪽 시프트(`<<`)**

```
value << 2   // 왼쪽으로 2칸

00001100 << 2 = 00110000
```

- 왼쪽으로 옮길 때, **빈자리에는 0을 넣는다.**

**오른쪽 시프트(`>>`)**

```
value >> 2   // 오른쪽으로 2칸

00001100 >> 2 = 00000011
10001100 >> 2 = 11100011
```

- 오른쪽으로 옮길 때, **빈자리에는 맨 앞자리에 있던 숫자를 그대로 채운다.**

> 이 시프트/비트 연산 방식은 **비트맵 파일 읽기 등 리틀 엔디안 바이트 해석**과 같은 실무 예제에도 그대로 적용된다.

## 7. 연산자 우선순위

- 여러 연산자가 섞인 식에서는 **소괄호 `()`를 명시적으로 쓰는 것이 중요**하다 — 우선순위를 암기해 판단하기보다, 괄호로 의도를 명확히 드러내는 편이 안전하다.
