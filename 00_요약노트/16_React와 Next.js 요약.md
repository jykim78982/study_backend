# React와 Next.js 요약

프론트엔드가 정적 페이지 → 서버 렌더링 → SPA를 거쳐 왜 **Next.js(SSR + React)** 에 이르렀는지, 그리고 Next.js에서 라우팅·컴포넌트·상태를 어떻게 다루는지를 정리한다.

## 1. 한눈에 보기

| 주제 | 핵심 |
|---|---|
| 프론트엔드의 변화 | 정적 웹 → 동적 서버 페이지 → 팻 클라이언트 → SPA → 풀스택 → SSR |
| SPA의 문제 | 문서를 클라이언트가 만들어서 검색엔진 노출이 어렵다 |
| Next.js | React 기반 풀스택 프레임워크. SSR로 검색엔진 문제를 해결한다 |
| 파일 기반 라우팅 | 폴더 구조가 곧 URL이다 |
| 중첩 레이아웃 | 레이아웃은 "틀"만 담당한다. 중첩해서 쓰고, 대체가 필요하면 라우트 그룹 |
| 동적 라우트 | 대괄호 폴더 `[slug]`. 구체적인 라우트가 우선한다 |
| 서버 / 클라이언트 컴포넌트 | 서버 컴포넌트가 기본. `"use client"`가 있으면 브라우저에서 동작하는 컴포넌트 |
| 하이드레이션 | 서버가 만든 완성 페이지에 스크립트가 붙어 동작하게 되는 과정 |
| 생명주기 | 마운트, 언마운트, `useEffect` |
| 상태 변수 | `useState`로 만든 값은 바뀌면 화면이 다시 그려진다 |
| 컴포넌트 분리 | 보이는 대로 나눈다. 트리 구조이고, 데이터는 각자 책임진다 |
| 서버 페이지의 상태 | 곧 URL(`searchParams`)이다 |

## 2. 개념 정리

### 2-1. 서버 컴포넌트와 클라이언트 컴포넌트

| | 서버 컴포넌트 | 클라이언트 컴포넌트 |
|---|---|---|
| 실행 위치 | 서버 | 서버(첫 렌더) + 브라우저 |
| 쓸 수 있는 것 | 데이터 패치, 비동기 `await` | `useState`, `useEffect`, 이벤트 |
| 선언 | 기본 | 파일 맨 위 `"use client"` |

- 데이터를 가져오는 위치가 서버면 검색엔진에 노출되는 HTML에 데이터가 이미 들어 있다.
- 상태나 이벤트가 필요한 부분만 클라이언트 컴포넌트로 떼어낸다.

### 2-2. 라우팅과 레이아웃

```
app/
  layout.js            ← 공통 틀
  (admin)/             ← 라우트 그룹: URL에는 안 나오고, 레이아웃을 따로 쓴다
    layout.js
    menus/[id]/page.js ← /menus/3 같은 동적 라우트
```

- `<a>` 대신 Next의 링크를 쓰면 페이지 전체가 새로고침되지 않는다.
- 상대 경로는 위치에 따라 달라지므로 절대 경로가 안전하다.

### 2-3. 컴포넌트를 나누는 기준

- 형제끼리 직접 지시하지 않는다. **트리 구조**이므로 부모를 통한다.
- 데이터는 부모가 다 가져와서 내려주기보다 **각 컴포넌트가 책임진다**.
- 페이지만 가질 수 있는 것: `searchParams`. 이것은 `Promise`라서 `await`한다.
- 서버 페이지의 상태(검색어, 페이지 번호)는 **URL에 반영**한다.

### 2-4. 자주 쓰는 패턴

```js
const next = [newItem, ...items];                      // 배열 맨 앞에 추가
<li className={selected ? "item on" : "item"}>…</li>   // 조건부 클래스
Array.from({ length: n }, (_, i) => i)                 // 정해진 개수만큼 반복
```

## 3. 자주 헷갈리는 것

- **SSR vs CSR:** SSR은 서버가 HTML을 만들어 보내고, CSR은 브라우저에서 만든다.
- **상태 변수 vs 일반 변수:** 일반 변수는 바뀌어도 화면이 다시 그려지지 않는다.
- **빌드 도구:** npm, pnpm, yarn, bun은 패키지 관리와 실행 속도에 차이가 있다.
- **서버 기반 vs 서버리스:** 항상 켜져 있는 서버와 요청 때만 실행되는 방식이다.
- 기업에서 Tailwind 대신 CSS Modules를 쓰는 이유는 참고자료에 정리했다.

## 4. 이 카테고리의 실습, 오답노트, 참고자료
