# 배열과 메모리 요약

배열은 **같은 타입의 값을 연속된 공간에 놓은 것**이고, 자바에서 배열 변수는 값이 아니라 **배열을 가리키는 참조**다. 이 사실이 이 카테고리 전체를 관통한다.

## 1. 한눈에 보기

| 주제 | 핵심 |
|---|---|
| 배열이 필요한 이유 | 변수를 하나씩 만들면 반복 코드가 늘어난다. 인덱스는 이름이 아니라 **연산**이다 |
| 배열 생성 3단계 | 참조 변수 선언 → `new`로 배열 생성 → 참조 연결 |
| 기본값 | 숫자는 0, 참조는 `null`로 자동 초기화된다 |
| 배열 대입 | 값 복사가 아니라 **주소 복사**다. 두 변수가 같은 배열을 가리킨다 |
| 2차원 배열 | "배열을 가리키는 배열". 접근은 1차원 접근 두 번이다 |
| 스택과 힙 | 지역변수와 매개변수는 스택, `new`로 만든 객체는 힙에 있다 |
| 스택 프레임 | 함수 호출 때 통째로 올라가고, 끝나면 통째로 내려간다 |
| 가비지 컬렉션 | 아무도 가리키지 않는 힙의 객체를 자동으로 수거한다 |
| 구조체(클래스) 배열 | 배열의 칸에는 객체 자체가 아니라 **객체를 가리키는 참조**가 들어 있다 |

## 2. 개념 정리

### 2-1. 배열 대입은 주소 복사

```java
int[] a = {1, 2, 3};
int[] b = a;      // 배열이 복사되는 게 아니라 같은 배열을 가리킨다
b[0] = 99;        // a[0]도 99가 된다
```

### 2-2. 클래스 배열과 `new`

```java
Exam[] exams = new Exam[3];   // 칸 3개만 생김. 안에는 모두 null
exams[0] = new Exam();        // 이때 비로소 객체가 생긴다
```

`new`가 있는 줄에서만 새 객체가 생긴다. 없는 줄은 기존 객체의 **참조만 복사**한다.

### 2-3. 메모리 영역

| 영역 | 담는 것 |
|---|---|
| 스택 | 지역변수, 매개변수(함수 호출마다 프레임 단위로 쌓인다) |
| 힙 | `new`로 만든 객체와 배열 |

### 2-4. 배열 실습 패턴

- **누적합:** 합계를 구한 뒤 평균을 낸다.
- **선형 탐색:** `index = -1`로 두고 찾으면 위치를 넣는다.
- **조건 필터링:** 개수를 세고, 배열을 만들고, 채운다(인덱스를 분리해서 쓴다).
- **swap과 버블 정렬:** 임시 변수를 두고 값을 맞바꾼다.

## 3. 자주 헷갈리는 것

- 중괄호 초기화(`{1, 2, 3}`)는 **선언할 때만** 가능하다.
- 참조를 덮어쓰면 이전 배열은 가리키는 곳이 없어져 GC 대상이 된다.
- `exam.kor`처럼 필드로 접근하는 값은 배열이 아니다. 배열인 것은 `exam` 자체를 담은 배열이다.
