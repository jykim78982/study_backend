# CSS 요약

CSS는 HTML 컨텐츠에 **스타일을 입히는 규칙**이다. 선택자로 대상을 고르고, 우선순위로 충돌을 해결하고, 박스 모델과 플렉스박스로 레이아웃을 짠다.

## 1. 한눈에 보기

| 주제 | 핵심 |
|---|---|
| Cascading | 여러 규칙이 겹치면 순서와 우선순위로 결정한다 |
| 적용 방법 | 인라인 대신 선택자로 쓴다. 파일은 코로케이션(관련된 것끼리 가까이) |
| 선택자 | 태그, 클래스, 아이디, 속성 선택자 |
| 콤비네이터 | 자손, 자식, 인접 형제, 일반 형제. 범위가 좁을수록 우선순위가 강하다 |
| 슈도 클래스 | 존재하지 않는 "상태"를 선택(`:hover`, `:nth-child` 등) |
| 슈도 엘리먼트 | 존재하지 않는 "요소"를 만들어 선택(`::before`, `::after`) |
| 우선순위 | 인라인 > 아이디 > 클래스·속성·슈도 클래스 > 태그 |
| 박스 모델 | 콘텐츠 + padding + border + margin. `box-sizing`으로 width의 기준을 정한다 |
| 플렉스박스 | 한 방향으로 아이템을 배치·정렬한다 |
| 배경 | 비트맵·벡터·그라데이션 세 형식, 여러 개를 겹쳐 쓸 수 있다 |
| mask | 배경색으로 아이콘 색을 자유롭게 바꾼다 |
| position | 수동 레이아웃. relative, absolute, fixed, sticky |
| transform | 이동, 확대, 회전, 비틀기 |

## 2. 개념 정리

### 2-1. 레이아웃 설계 순서

1. 방(레이아웃)을 먼저 만들고, 콘텐츠는 나중에 채운다.
2. 시맨틱 태그가 아닌 곳에는 클래스로 이름을 명시한다.
3. 공통 스타일은 `link`로 포함한다(`@import`보다 낫다).
4. 높이 `100%`의 함정과 `margin` 초기화에 주의한다.
5. `calc()`로 나머지 영역을 채운다.
6. 플렉스박스로 다시 짠다.

### 2-2. 플렉스박스 속성

| 속성 | 하는 일 |
|---|---|
| `flex-direction`, `flex-wrap` | 방향과 줄바꿈 |
| `flex-basis`, `flex-grow`, `flex-shrink` | 기본 크기와 신축 비율 |
| `align-items` / `align-content` | 한 줄 안의 아이템 정렬 / 줄 자체의 정렬 |
| `align-self` | 이 아이템만 다르게 정렬 |
| `order` | 마크업 순서를 바꾸지 않고 화면 순서만 바꾼다 |

### 2-3. 화면이 만들어지는 과정

HTML → **DOM**, CSS → **CSSOM** → 합쳐서 렌더링 트리 → 레이아웃 → 그리기.

## 3. 자주 헷갈리는 것

- **`id`는 스타일 이름표가 아니라** 문서상의 고유 식별자다. 스타일은 주로 클래스로 건다.
- **인라인 엘리먼트는 박스가 아니다.** 그래서 폭과 높이가 먹지 않는다.
- `align-items`와 `align-content`는 줄이 하나일 때와 여러 줄일 때 차이가 난다.
- `is()`와 `where()`는 둘 다 묶어 주지만 우선순위가 다르다.
