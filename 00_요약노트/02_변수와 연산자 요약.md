# 변수와 연산자 요약

변수가 값을 직접 담는지 **다른 곳을 가리키는지**를 구분하는 것이 이 카테고리의 출발점이다. 그 위에 연산자와 형 변환, 문자열 다루기가 올라간다.

## 1. 한눈에 보기

| 주제 | 핵심 |
|---|---|
| 값 변수 / 참조 변수 | 값 변수는 값 자체를 담고, 참조 변수는 객체를 가리키는 "이름표"다 |
| 문자열 | 문자열도 객체다. 리터럴로 만들면 같은 객체를 공유하고, `new`로 만들면 별개의 객체가 된다 |
| 형 변환 | 작은 타입 → 큰 타입은 자동, 큰 타입 → 작은 타입은 직접 지정(값 손실 주의) |
| 연산자 | 산술, 증감, 비교, 논리, 복합 대입, 비트, 시프트. 우선순위가 있다 |
| 문자열 메서드 | 길이, 검색, 자르기, 치환, 분리·결합, `StringBuilder` |
| 컴파일 실행 규칙 | `main` 시그니처 고정, 패키지·클래스패스, 표준 클래스와 이름이 겹치면 안 된다 |

## 2. 개념 정리

### 2-1. 값 변수와 참조 변수

```java
int a = 10;                  // 값 변수: a 안에 10이 들어 있다
String s = "hello";          // 참조 변수: s는 문자열 객체를 가리킨다
```

- 참조 변수끼리 `==`로 비교하면 **같은 객체인지**를 비교한다. 내용 비교는 `equals`를 쓴다.
- `null`은 "가리키는 객체가 없음"이다. 빈 문자열(`""`)과는 다르다.

### 2-2. 문자열 비교

| 방식 | 결과 |
|---|---|
| `"a" == "a"` (리터럴끼리) | 같은 객체라서 `true` |
| `new String("a") == new String("a")` | 서로 다른 객체라서 `false` |
| `equals` | 내용을 비교해서 `true` |

### 2-3. 연산자

- 나눗셈은 정수끼리 하면 소수점이 버려진다.
- 증감 연산자(`++`, `--`)는 앞에 붙이느냐 뒤에 붙이느냐에 따라 값이 쓰이는 시점이 다르다.
- 논리 연산자는 단락 평가를 한다(앞에서 결과가 정해지면 뒤를 실행하지 않는다).

## 3. 자주 헷갈리는 것

- 문자열 비교에 `==`를 쓰면 의도와 다르게 동작한다. 내용 비교는 항상 `equals`.
- 클래스 이름을 `String`처럼 표준 클래스와 겹치게 지으면 문제가 생긴다.
- 파일을 분리했으면 `javac`로 컴파일해야 하고, 컴파일 방식을 섞으면 `IllegalAccessError`가 날 수 있다.

## 4. 이 카테고리의 오답노트

- 문자열 비교
