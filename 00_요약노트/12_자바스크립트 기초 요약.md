# 자바스크립트 기초 요약

자바스크립트는 **브라우저 플랫폼 위에서 DOM을 조작하는 언어**로 시작했다. 이 카테고리는 DOM과 이벤트, 데이터 타입, ES6 문법, 그리고 자바스크립트 생태계가 어떻게 React로 이어졌는지를 다룬다.

## 1. 한눈에 보기

| 주제 | 핵심 |
|---|---|
| 프로그램 = 언어 + 플랫폼 | 브라우저가 플랫폼이고, DOM이 그 API다 |
| DOM | 메모리에 로드된 동적 HTML. 모든 구성 요소는 `Node`를 상속한다 |
| 노드 선택 | `getElement*` 계열과 Selectors API(`querySelector`) |
| 이벤트 | 새로운 진입점. 캡처링 → 타깃 → 버블링 순서로 실행된다 |
| 이벤트 위임 | 반복 바인딩 대신 부모에 한 번만 등록하고 `event.target`으로 구분한다 |
| 기본 행위 | `preventDefault()`로 막고, `stopPropagation()`으로 버블링을 막는다 |
| 데이터 타입 | 원시 6가지, 래퍼 객체, 배열, 객체, JSON |
| 비교 | `==`(자동 형변환)과 `===`(타입까지 비교) |
| ES6 | `let`/`const`, 템플릿 리터럴, 구조 분해, 스프레드, 옵셔널 체이닝 |
| 클로저 | 아우터 변수를 붙잡고 있는 함수 |
| 자바스크립트 진화 | AJAX → SPA → jQuery → MVC → Angular·Vue·React → Flux |
| React의 핵심 | 가상 DOM, JSX, 컴포넌트, 번들링 |

## 2. 개념 정리

### 2-1. 이벤트 흐름

```
window → … → 부모 → 타깃        (캡처링: 내려감)
타깃 → 부모 → … → window        (버블링: 올라감)
```

- 기본적으로 버블링 단계에서 핸들러가 실행된다.
- 이벤트 객체(`target`, `currentTarget`)로 조건 분기하고, 조건이 안 맞으면 조기 반환한다.

### 2-2. 변수 선언

| | 재선언 | 재할당 | 스코프 | 호이스팅 |
|---|---|---|---|---|
| `var` | 가능 | 가능 | 함수 | 선언이 끌어올려지고 `undefined`로 초기화 |
| `let` | 불가 | 가능 | 블록 | 일시적 사각지대(TDZ) |
| `const` | 불가 | 불가 | 블록 | 일시적 사각지대(TDZ) |

### 2-3. 자주 쓰는 ES6 문법

```js
const { name, price } = menu;            // 객체 구조 분해
const [first, ...rest] = list;           // 배열 구조 분해, 나머지 매개변수
const next = [newItem, ...list];         // 스프레드로 맨 앞에 추가
const text = `${name}: ${price}원`;       // 템플릿 리터럴
const city = user?.address?.city;        // 옵셔널 체이닝
const v = input ?? "기본값";              // null 병합
```

### 2-4. 참 같은 값과 거짓 같은 값

`false`, `0`, `""`, `null`, `undefined`, `NaN`은 거짓 같은 값이다. `||`와 `&&`는 단락 평가로 값을 그대로 돌려준다.

### 2-5. DOM에 HTML 이어붙이기

`innerHTML +=`는 기존 DOM을 전부 지우고 다시 만든다. `insertAdjacentHTML`은 기존 DOM을 건드리지 않고 끼워 넣는다.

## 3. 자주 헷갈리는 것

- **함수는 "정의"가 아니라 "객체 생성"**이다. 그래서 변수에 담고 매개변수로 넘길 수 있다.
- **원시값이 객체처럼 쓰이는 이유:** 자동 박싱으로 래퍼 객체가 잠깐 만들어진다.
- **`id` 네이밍:** 전역 객체에 자동 등록되는 함정이 있다.
- **기술적 우수성과 인기는 별개다.** Angular가 밀리고 React가 남은 것이 예다.
- **JSX는 HTML이 아니다.** 문법 규칙(닫는 태그, `className` 등)을 지켜야 한다.
