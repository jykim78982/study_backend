# AJAX 오답노트

### 1. AJAX 관련 기술과 특징으로 맞는 조합은 어떤 것인가?

**문제**: AJAX 관련 기술과 특징으로 맞는 조합은 어떤 것인가?

1. AJAX는 동기 통신을 기본으로 하며 XML만 사용한다
2. AJAX는 브라우저의 UI 스레드를 차단하도록 설계되었다
3. AJAX는 서버에서 완전한 HTML 문서를 항상 반환해야 한다
4. AJAX는 비동기 통신을 사용하고 현재는 JSON이 일반적인 데이터 형식이다

**정답: 4번**

- AJAX(Asynchronous JavaScript and XML)는 이름에 XML이 들어있지만 핵심은 "비동기적으로 데이터를 주고받아 전체 페이지를 다시 로드하지 않고 일부만 갱신하는 기술"이라는 데 있다. 과거에는 데이터 교환 형식으로 XML을 많이 썼지만, 구문이 복잡하고 용량이 커서 지금은 더 가볍고 읽기 쉬운 JSON이 사실상 표준처럼 쓰인다.
- **1번이 오답인 이유**: AJAX의 핵심은 동기가 아니라 **비동기(Asynchronous)** 통신이다. 데이터 전송 형식도 XML에 국한되지 않고 JSON, HTML 조각, 순수 텍스트 등 다양한 포맷을 쓸 수 있다.
- **2번이 오답인 이유**: 동기 통신을 하면 데이터가 도착할 때까지 브라우저 화면이 멈추고 클릭도 안 되는 UI 차단(Blocking)이 발생한다. AJAX는 정확히 이 문제를 피하려고 백그라운드에서 비동기로 요청을 처리해 UI 스레드가 차단되지 않도록 만든 기술이다.
- **3번이 오답인 이유**: 전통적인 방식은 페이지 전체를 다시 그리기 위해 완전한 HTML 문서를 서버가 응답해야 했다. AJAX는 화면 갱신에 필요한 순수 데이터(JSON 등)만 받아서, 자바스크립트로 원하는 위치의 DOM만 부분적으로 바꾼다.

**전통적 방식과 AJAX 방식의 차이**

| 구분 | 전통적 방식 | AJAX 방식 |
|---|---|---|
| 통신 방식 | 동기 | 비동기 |
| 서버 응답 | 완전한 HTML 문서 | JSON 등 순수 데이터 |
| 화면 갱신 | 페이지 전체 새로고침 | 필요한 DOM만 부분 갱신 |
| UI 스레드 | 응답 대기 중 차단됨 | 차단되지 않음 |
| 데이터 형식(과거→현재) | XML 중심 | JSON이 일반적 |

한 줄로 정리하면, AJAX는 전체 페이지 새로고침 없이 백그라운드에서 비동기로 서버와 JSON 등의 데이터를 주고받는 기술이다.
