# V8 엔진과 Node.js 오답노트

### 1. V8 엔진의 주요 역할은 무엇인가?

**문제**: V8 엔진의 주요 역할은 무엇인가?

1. 비동기 이벤트의 스케줄링을 담당한다
2. 패키지 의존성을 관리하는 레지스트리 역할을 한다
3. JSON 문자열을 파싱하고 직렬화하는 전용 모듈이다
4. JavaScript 코드를 기계어 수준으로 실행하고 최적화한다

**정답: 4번**

- V8은 구글이 만든 오픈소스 자바스크립트 엔진으로, 텍스트로 작성된 자바스크립트 코드를 바이트코드로 바꾸고 이를 다시 JIT(Just-In-Time) 컴파일해서 CPU가 직접 실행할 수 있는 기계어로 변환·최적화하는 역할을 한다. 크롬 브라우저와 Node.js 둘 다 이 V8 위에서 자바스크립트를 실행한다.
- **1번이 오답인 이유**: 비동기 이벤트를 큐에 쌓고 순서대로 꺼내 실행하는 것은 V8이 아니라 **이벤트 루프**의 역할이다. 이벤트 루프는 V8 엔진 자체에 포함된 기능이 아니라, V8을 감싸고 있는 실행 환경(브라우저 또는 Node.js 런타임)이 별도로 제공하는 장치다.
- **2번이 오답인 이유**: 패키지 의존성을 저장·관리하는 레지스트리는 `npm`이다. V8은 코드 실행 엔진이지 패키지 관리와는 무관하다.
- **3번이 오답인 이유**: `JSON.parse`/`JSON.stringify`는 자바스크립트 언어 명세에 포함된 내장 기능일 뿐, V8만의 전용 모듈이 아니다.

**V8과 이벤트 루프의 역할 분리**

| 구성 요소 | 역할 |
|---|---|
| V8 엔진 | 자바스크립트 코드를 기계어로 컴파일·실행·최적화 |
| 이벤트 루프 | 비동기 작업(I/O, 타이머 등)의 완료를 감지해 콜백을 순서대로 실행 |
| Node.js 코어 API | 파일·네트워크 등 OS 자원에 접근하는 내장 모듈(`fs`, `http`) 제공 |
| npm | 외부 패키지를 설치·배포하는 레지스트리 |

즉 "자바스크립트를 실행하는 것"과 "비동기 작업을 스케줄링하는 것"은 서로 다른 부품이 나눠 맡고 있고, V8은 오직 앞쪽(코드 실행) 역할만 담당한다는 점이 이 문제의 핵심이다.
