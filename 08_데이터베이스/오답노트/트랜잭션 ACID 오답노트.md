# 트랜잭션 ACID 오답노트

### 1. "성공적으로 완료되면 시스템 장애에도 영구 반영되어야 한다"는 어떤 특성인가

**문제**: PostgreSQL 데이터베이스 트랜잭션(Transaction)의 ACID 특성 중 "트랜잭션이 성공적으로 완료되면 시스템 장애가 발생하더라도 영구적으로 반영되어야 한다"를 의미하는 것은?

1. 원자성 (Atomicity)
2. 일관성 (Consistency)
3. 격리성 (Isolation)
4. 지속성 (Durability)

**정답: 4번**

ACID는 데이터베이스 트랜잭션이 안전하게 수행됨을 보장하는 네 가지 성질이다.

| 성질 | 의미 |
|---|---|
| 원자성 (Atomicity) | "All or Nothing". 트랜잭션 내 모든 작업이 다 처리되거나, 하나라도 실패하면 전부 취소(Rollback)된다 |
| 일관성 (Consistency) | 트랜잭션 전후의 데이터베이스는 미리 정해진 제약조건·규칙을 항상 만족해야 한다 |
| 격리성 (Isolation) | 여러 트랜잭션이 동시에 실행되어도 서로 영향을 주지 않고 독립적으로 수행되어야 한다 |
| 지속성 (Durability) | 성공적으로 커밋(commit)된 트랜잭션의 결과는 시스템 다운·장애가 발생해도 데이터베이스에 영구적으로 보존되어야 한다 |

문제의 조건("성공적으로 완료" + "시스템 장애가 발생하더라도" + "영구적으로 반영")은 커밋 이후 결과가 사라지지 않는다는 뜻이므로 **지속성(Durability)**에 해당한다. 원자성은 "전부 되거나 전부 안 되거나"의 문제이고, 일관성은 제약조건 위반 여부, 격리성은 동시 실행 트랜잭션 간의 간섭 문제라서 이 문제의 조건과는 맞지 않는다.
